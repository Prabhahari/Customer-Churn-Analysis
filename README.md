# Customer Churn Analysis

## 📊 Project Overview

This project analyzes customer churn data using Microsoft Power BI to identify churn trends, customer retention patterns, and key factors associated with customer exits.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## 📈 Dashboard

### 1. Churn Overview
- Total Members
- Active & Inactive Customers
- Exit & Retained Customers
- Customer trends by year and month
- Exit customers by gender and credit type
- Interactive filters

### 2. Churn Analysis
- Monthly churn rate by year
- Exit customers by credit card status
- Retained customers by credit type
- Churn rate by category
- Interactive filters

## 🎯 Project Objective

To transform customer churn data into meaningful business insights that help understand customer behavior and support customer retention strategies.
